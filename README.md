# Nexora AI  
### AI-Powered Content Automation Platform

This repository contains the **conceptual system design and AI architecture** for **Nexora AI**, created using **Kiro** as part of the **AI for Bharat Hackathon – Prompt Challenge**.

## Overview
Nexora AI is an AI-powered content automation platform designed to help creators, businesses, and teams generate, review, schedule, and publish content using Generative AI with human-in-the-loop control.
